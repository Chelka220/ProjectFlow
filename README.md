 ProjectFlow

 Описание проекта

ProjectFlow — информационная система для управления проектами и задачами.

 Основные возможности

* Регистрация и авторизация пользователей.
* Разграничение прав пользователей по ролям.
* Создание и редактирование проектов и задач.
* Назначение исполнителей и сроков выполнения.
* Изменение статусов задач.
* Просмотр отчётов.
* Автоматический запуск тестов через GitHub Actions.

 Технологии

* Python 3.11
* Flask
* Flask-SQLAlchemy
* SQLite
* Pytest
* Git и GitHub Actions

 Запуск проекта

1. Установить Python 3.11.
2. Создать виртуальное окружение.
3. Установить необходимые зависимости.
4. Запустить приложение командой `python app.py`.

Для запуска тестов выполнить `python -m pytest -v`.

## Автоматическое тестирование

GitHub Actions запускает тесты при отправке изменений в настроенные ветки репозитория.
